# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Instead, use GitHub's
[private vulnerability reporting](https://github.com/cosmo030/glyph-garden/security/advisories/new)
for this repository.

Include what you found, how to reproduce it, and which browser and version you used. You'll get a
reply as soon as possible.

## Scope

Glyph Garden is a new-tab page. It has no server, makes no network requests, and only asks for the
`storage` and `search` permissions. Reports about anything that could change that (for example a
way to make the page load remote code or leak data) are especially welcome.
